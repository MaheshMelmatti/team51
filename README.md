# Team 51 Project

## Structure
```
team51/
├── index.html        # Main page (owner)
├── css/
│   └── style.css     # Base styles (owner)
├── js/
│   └── main.js       # Main script (owner)
├── members/
│   ├── member1.js    # Added by Member 1
│   ├── member2.js    # Added by Member 2
│   └── member3.js    # Added by Member 3
└── README.md
```

## How to contribute (teammates)
1. Clone the repo: `git clone <repo-url>`
2. Add your file inside `members/` folder
3. Commit: `git add . && git commit -m "Add memberX file"`
4. Push: `git push origin main`
